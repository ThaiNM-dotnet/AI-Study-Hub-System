# AI Study Hub
AI-powered Study Document Management System for University Students.
---

# 📚 Introduction
AI Study Hub is a modern web-based platform developed to help students store, manage, search, and interact with study materials using Artificial Intelligence. During the learning process, students often face many problems:
  * Study documents are scattered across multiple platforms:
  * Google Drive
  * Messenger
  * Facebook Groups
  * Email
  * USB storage
  * Difficult to find old files
  * No clear document classification system
  * Manual document sharing
  * Limited local storage capacity
  * Cannot quickly ask about document content
Therefore, this system is developed to:
  * Centralize study document management
  * Reduce document loss
  * Improve search and access efficiency
  * Create a convenient document-sharing environment
  * Integrate AI chatbot support for studying
  * Simulate a real-world fullstack software development process
---

# 🎯 Objectives
The system aims to:
  * Support students in managing study materials efficiently
  * Store files securely on cloud storage
  * Provide fast document search capability
  * Integrate AI chatbot for learning support
  * Improve collaboration and document sharing
  * Provide a modern SaaS-style learning experience
